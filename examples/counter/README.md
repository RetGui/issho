# Counter Example

A small example showing how issho can be used by a custom UI framework.

## Run

From the repository root:

```sh
cargo run -p issho-counter
```

## Controls

- Click the left or right button to decrement or increment the counter.
- Press <kbd>Arrow Down</kbd> or <kbd>Arrow Up</kbd> to change the value.
- Press <kbd>Enter</kbd> or <kbd>Space</kbd> to activate the focused counter
  button.
